🦅 HawkChroma — Word/Excel/PPT Split-Screen, Bluetooth & USB Guide

📲 Why Split-Screen Didn't Work Before & How It Works Now (Word, Excel & PowerPoint Mobile)

The Root Cause: First, if HawkChroma was running inside a sandboxed preview frame, the mobile OS blocked clipboard access unless you opened the standalone HTML file in Chrome/Safari. Second, the mobile versions of Word, Excel, and PowerPoint often ignore plain-text #RRGGBB strings when you paste directly onto a cell or slide, or their custom hex input boxes reject the leading # symbol.

How HawkChroma Fixes It (3 Built-In Modes in Bar 2):

  • 1. Office Rich Cell/Shading Fill (Default): HawkChroma now writes a dual Rich HTML + Plain Text payload to your phone clipboard. In Excel Mobile, tap any cell and tap Paste — it pastes a pre-colored cell fill directly! In Word / PowerPoint Mobile, tapping Paste inserts a pre-shaded color block or colored text.
  • 2. 6-Digit Hex (No #): Select this in Bar 2 when using the More Colors → Custom Hex box in Word/Excel/PPT Mobile so it pastes clean 6-character hex (10B981) without getting rejected for the # character.
  • 3. Split-Screen Drag & Drop (✋ Drag to App): Long-press and drag the ✋ Drag to App chip from Bar 2 across the split-screen divider directly into Word or PowerPoint!
  • Tip: Always open foldable_2x10_keyboard_app.html directly in mobile Chrome or Safari (not inside a chat preview frame) when using Split Screen so your phone OS allows full clipboard and drag-and-drop sharing.
📘 Bluetooth (BLE) Mode — What Works & How to Connect

How Browser Bluetooth Works: Web apps use the Web Bluetooth API (navigator.bluetooth in Chrome on Android/Windows/Mac), which operates as a GATT Central:

  • Direct Hardware Pairing (Works Native in Chrome): Tap 📘 Pair BLE Device in Bluetooth mode to connect your phone directly to an nRF52840 / ESP32 Bluetooth board (such as Board B from our CAD design) or a PC running a BLE UART receiver. Every key tap streams live over Bluetooth Low Energy!
  • Phone-as-BLE-HID Keyboard to PC: Because mobile operating systems restrict web pages from spoofing a hardware Bluetooth HID keyboard peripheral directly, if you want your phone to appear as a native Bluetooth Keyboard in Windows/Mac Bluetooth settings with zero wires, you can either use Windows Cloud Clipboard / Link to Windows (instant wireless sync) or run the free Android Bluetooth Keyboard & Mouse companion app alongside HawkChroma.
1. Windows PC Mode (Cloud Clipboard & AutoHotkey Ribbon Injector)

Turn on Cross-device copy and paste in Windows 11 Settings → System → Clipboard (or Microsoft Link to Windows). Every key tap lands on your Windows clipboard immediately. Optional AutoHotkey v2 script to auto-apply hex fills in Excel/PowerPoint:

; HawkChroma Windows AutoHotkey v2 — Press Ctrl+Shift+V in Excel/PPT ^+v:: { hex := Trim(A_Clipboard, "# ") if RegExMatch(hex, "^[0-9A-Fa-f]{6}$") { Send("!h") Sleep(80) Send("h") Sleep(80) Send("m") Sleep(150) Send("^v{Enter}") } }
2. USB Cable Mode (Use Phone as a Wired USB Color Keyboard)

Connect your phone to your computer with a USB-C cable. Enable USB Tethering or run adb reverse tcp:8765 tcp:8765, run this Python receiver on your PC, and tap Link ADB in USB Cable mode (or use Pair USB Serial for 115200 baud WebSerial):

# HawkChroma USB Cable Receiver (pip install websockets pyperclip) import asyncio, json, websockets, pyperclip async def handler(ws): async for msg in ws: d = json.loads(msg) pyperclip.copy(d["formatted"]) print(f"[HawkChroma USB] {d['label']} -> {d['formatted']}") async def main(): async with websockets.serve(handler, "0.0.0.0", 8765): await asyncio.Future() asyncio.run(main())
